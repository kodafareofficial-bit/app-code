# کد آفر (Code Offer)

اپ فلاتر + بک‌اند + پنل مدیریت (داخل خود اپ) + ورک‌فلو ساخت APK با GitHub Actions.

## ساختار
- `lib/` اپ فلاتر (بخش مشتری + پنل مدیر)
- `backend/` سرور Node.js بدون وابستگی (نیاز به Node ≥ 22.13) با دیتابیس SQLite
- `.github/workflows/build-apk.yml` ساخت خودکار APK
- `tool/` اسکریپت‌های کمکی بیلد

## ۱) راه‌اندازی بک‌اند (روی سرور)
```bash
cd backend
cp .env.example .env     # ADMIN_EMAIL و ADMIN_PASSWORD را حتماً تغییر دهید
docker compose up -d --build   # از ریشه پروژه  (یا: npm start)
```
- حتماً جلوی سرور یک HTTPS (Caddy / nginx) بگذارید و آدرس نهایی را مثلاً `https://api.example.com` در نظر بگیرید.
- ادمین ثابت است: ایمیل/رمز از `.env` خوانده می‌شود و با هر اجرا همان اعمال می‌شود.
- تست: `cd backend && npm test`

## ۲) ساخت APK با گیت‌هاب
1. پروژه را در یک مخزن GitHub بالا ببرید (push به `main`).
2. در مخزن: Settings → Secrets and variables → Actions → **Variables** → متغیر `API_BASE_URL` را برابر آدرس سرور بگذارید.
3. تب Actions → «Build Android APK» → Run workflow (یا با هر push اجرا می‌شود).
4. فایل APK در بخش **Artifacts** همان اجرا است. با push تگ مثل `v1.0.0` در Releases هم قرار می‌گیرد.

### امضای حرفه‌ای (پیشنهادی)
بدون امضای ثابت، هر بیلد کلید متفاوتی دارد و کاربران نمی‌توانند روی نسخه قبل آپدیت کنند. یک بار کلید بسازید:
```bash
keytool -genkey -v -keystore upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
base64 -w0 upload.jks   # خروجی را در Secret بگذارید
```
Secrets: `KEYSTORE_BASE64`, `KEYSTORE_PASSWORD`, `KEY_ALIAS`, `KEY_PASSWORD`. فایل `.jks` را هرگز commit نکنید.

## ۳) استفاده
- ورود مدیر: صفحه ورود → «ورود مدیر» (ایمیل و رمز).
- **تنظیمات → پنل پیامکی ippanel**: توکن، شماره ارسال‌کننده و کد الگو را وارد و پیامک آزمایشی بزنید.
  تا وقتی پیامک فعال نشود، کد تایید فقط در لاگ سرور چاپ می‌شود.
- هر تغییر مدیر (لوگو، رنگ، خدمات، بنر، شبکه‌ها) حداکثر ظرف ~۴۵ ثانیه یا با باز کردن اپ برای کاربران اعمال می‌شود.
- خروجی کاربران: داشبورد یا تب کاربران → دکمه CSV (قابل باز شدن در اکسل).

## نکات
- لوگوی آیکن لانچر هنگام بیلد از `assets/logo.png` و `assets/logo_foreground.png` ساخته می‌شود؛ برای تغییر، این دو فایل را عوض کنید. لوگوی داخل اپ و اسپلش از پنل مدیر عوض می‌شود.
- فونت وزیرمتن هنگام بیلد دانلود می‌شود؛ برای اطمینان می‌توانید سه فایل `Vazirmatn-{Regular,Medium,Bold}.ttf` را در `assets/fonts` بگذارید.
- اعلان‌ها هنگام باز بودن اپ (و با بازگشت به اپ) نمایش داده می‌شوند. نوتیفیکیشن Push وقتی اپ کاملاً بسته است نیاز به Firebase (FCM) دارد که در این نسخه نیست.
